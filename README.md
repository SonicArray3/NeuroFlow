Inspiration:

Studying can be overwhelming—traditional methods often feel ineffective. We wanted to create a tool that makes studying engaging, adaptive, and fun, helping users stay focused and learn more efficiently.

What it does:

NeuroFlows is an AI-powered study tool that enhances learning through:

AI Flashcards & Quizzes – Adaptive learning that prioritizes key concepts. Smart Study Plans – AI-generated schedules based on focus levels and habits. Learning Pattern Tracking – Detects distractions and adjusts study sessions. Study Rooms & Community – Collaborative virtual spaces for group learning. Gamification – XP, streaks, and achievements to make studying rewarding. How we built it We developed NeuroFlows using Gadget as our backend, handling authentication and API integrations seamlessly. The frontend was built with React, and we incorporated AI models to generate flashcards, quizzes, and adaptive study plans.
